# LED Dimmer

[![License: Apache](https://img.shields.io/badge/license-APACHE-brightgreen.svg?style=for-the-badge)](/LICENSE.md)

**Rev:** 1.0

A compact analog LED dimmer PCB using a 555 timer to generate an adjustable PWM signal that drives a logic-level MOSFET for smooth LED brightness control.

![RGB LED Dimmer Rotating View](rgb-led-dimmer.gif)

## Features

- **Single-Channel PWM Control:** Adjustable LED brightness
- **PWM Generator:** 555 timer based oscillator
- **Adjustable Brightness:** 50kΩ potentiometer
- **MOSFET Output Stage:** Logic-level N-channel MOSFET switching
- **Supply Voltage:** 12V DC input
- **LED Compatibility:** Suitable for LEDs and LED strips with appropriate current limiting
- **PCB:** Compact 2-layer layout with ground plane
- **Output Connector:** Dedicated LED output header
- **Modular Power Input:** Designed to pair with external regulated power modules

## Design Overview

### PWM Generation

The circuit uses a **555 timer configured as an adjustable PWM oscillator**. The duty cycle is controlled using a 50kΩ potentiometer with steering diodes that allow independent control of the charge and discharge paths.

This configuration provides:

- Smooth brightness adjustment
- Wide PWM duty cycle range
- Consistent LED brightness control without changing LED current

### Output Stage

The PWM signal drives the gate of a **logic-level N-channel MOSFET** through a gate resistor.

The MOSFET operates as a **low-side switch**, allowing efficient PWM dimming of the connected LED load.

Key characteristics:

- Low gate drive requirements
- Minimal heat generation at typical LED currents
- Suitable for individual LEDs, LED strings, and low-power LED stripss

### Power Input

The board operates from a **12V DC supply**.

A local **bulk capacitor** stabilizes the supply rail and reduces switching noise generated by the PWM circuit.

Typical supply sources include:

- External 12V power supplies
- USB-C PD trigger modules
- DC bench supplies

### LED Output

The output header provides connections for:

- **PWM-switched output**
- **Supply rail**

LEDs must include appropriate **current-limiting resistors**, unless the connected LED module or strip already incorporates them.

## Electrical Specifications

- **Input Voltage:** 12V DC
- **PWM Channels:** 1
- **Control Method:** Analog PWM dimming
- **Switching Device:** Logic-level N-channel MOSFET

## Key Components

- **U1:** 555 Timer IC (PWM generator)
- **Q1:** IRLML6344 N-channel MOSFET (LED switching)
- **VR1:** 50kΩ potentiometer (brightness control)
- **D1–D2:** Signal diodes (PWM steering network)
- **C10:** Bulk supply capacitor
- **J1:** LED output connector
- **J2:** Power input connector
